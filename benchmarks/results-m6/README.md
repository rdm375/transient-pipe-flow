# M6 numerical characterization

This directory is generated by `make characterize`.  The case is an
independently constructed 100 km, 1 m diameter isothermal pipe using the
constant-Z EOS and Swamee-Jain friction already validated in M1-M5.  It
starts from the exact 100 kg/s steady state at 8 MPa inlet pressure and
uses a C1-smooth half-cosine downstream demand transition from 100 to
105 kg/s over 1800 s.  The smooth forcing avoids derivative corners that
would obscure formal temporal convergence.

## Temporal refinement

`temporal.csv` holds N=40 fixed and uses theta=0.5.  The reference is the
same N=40 grid with dt=3.75 s.  Halving dt from 120 to 60 to 30 to 15 s
reduces outlet-pressure error by approximately a factor of four, showing
the expected near-second-order Crank-Nicolson behavior for this smooth
case.  The frozen regression envelope at dt=60 s is relative outlet
pressure error <= 5e-7.

## Spatial refinement

`spatial.csv` holds dt=7.5 s and theta=0.5 fixed.  The reference is N=100
at the identical dt, so temporal truncation error is not mixed into the
spatial comparison.  N=10, 20, 40, and 80 converge monotonically toward
the N=100 result; the coarse-grid refinement ratios are consistent with
approximately second-order spatial behavior.  The frozen N=40 envelope
is relative outlet-pressure error <= 2e-7.

## Theta study

`theta.csv` compares theta = 0.50, 0.55, 0.60, 0.65, 0.70, 0.80, and
1.00 at N=40 and dt=60 s against a dt=3.75 s, theta=0.5 reference on the
same grid.  Theta=0.5 gives the smallest outlet-pressure error in this
smooth transient, as expected for the second-order member of the family.
Increasing theta above 0.5 introduces progressively stronger first-order
implicit bias/numerical damping.  Theta=0.65 remains well inside the
frozen engineering baseline, with relative outlet-pressure error below
7e-7, while providing the intended damping margin.

These tolerances are regression envelopes, not claims of physical-model
accuracy.  They apply only to this frozen numerical characterization
case and should not be loosened merely to accommodate unexplained
changes.
